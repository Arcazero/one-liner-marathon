A single original one-line comedy joke for make.fun's "One-Liner Marathon" bounty: a deadpan office joke about a parrot that learned corporate speak. The program writes the joke to /output/entry.txt, where the judge compares it head to head against other entries on funniness.

## Run it

```sh
python3 main.py
```
